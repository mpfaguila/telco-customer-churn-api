# Dataset

**Caso:** Customer Churn em Telecom.

**Arquivo utilizado:** `data/raw/Telco_customer_churn.xlsx`

**Referência informada:** https://www.kaggle.com/datasets/yeanzc/telco-customer-churn-ibm-dataset

A base possui 7.043 clientes e 33 colunas. O target usado é `Churn Value` (0 = não churn; 1 = churn).

Para modelagem, usamos 19 variáveis de produto, relacionamento e cobrança. Campos identificadores/geográficos e campos que podem carregar informação posterior ou diretamente derivada do churn são excluídos do modelo.
